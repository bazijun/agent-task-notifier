# 平台支持

事件源是产生任务事件的工具；通知渠道负责将事件发送到接收设备。两者独立配置。当前事件源仅支持 Codex，通知渠道支持 Bark、ntfy、飞书群机器人、企业微信群机器人、WxPusher 和 iMessage。

| 事件源 | 状态 | 接入方式 |
|---|---|---|
| Codex | 已支持 | 安装器配置 `notify`、`UserPromptSubmit` 和 `PermissionRequest` Hook。 |
| Cockpit 中的 Codex 实例 | 已支持 | 按独立 `CODEX_HOME` 安装，保留已有的 Cockpit 通知回调。 |
| Claude Code | 未接入 | 需要独立的事件解析和安装器；现有 Codex 安装命令不适用。 |
| Cursor | 未接入 | 需要先确认可用的任务完成、授权事件接口，再实现适配器。 |
| 其他 agent 工具 | 未接入 | 需要逐一确认事件接口和可支持的通知时机。 |

Codex 安装器目前面向 macOS。接收设备可以是 iPhone/iPad 或 Android；接收设备类型不改变事件源的支持范围。各通知渠道的首次配置方式见 [README](../README.md#首次配置macos)。

## 新事件源接入要求

新增事件源需要独立处理该工具的事件格式、配置文件和安装流程，并将可确认的任务完成或等待授权事件交给现有通知渠道。适配器应过滤工具内部轮次和子 agent 事件，避免重复提醒。接入时需用脱敏事件样例验证过滤和通知内容，并补充对应的安装说明。

目前没有跨事件源的统一适配器接口。新增平台的支持状态以实际实现和测试为准。
